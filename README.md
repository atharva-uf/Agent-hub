# Agent Hub — Agentic Developer Portal

A terminal-native developer portal for browsing repositories, viewing code health insights, and triggering AI agent tasks against live codebases. Built as a fully mocked single-page application with realistic streaming execution simulation.

---

## Getting Started

```bash
bun run dev        # Start local dev server (Vite)
bun run build      # Production build (client + SSR)
bun run preview    # Preview production build locally
bun run lint       # ESLint
bun run format     # Prettier (writes in place)
```

> Requires [Bun](https://bun.sh) — no other runtime dependencies.

---

## Features

- **Repository browser** — 12 mocked repos with search (name, description, tags), language filter, and health status filter
- **Repo detail view** — commit metadata, open PRs, branch selector, build status, and 6 insight metric cards (stars, contributors, test coverage, open issues, deploys, avg PR time)
- **Agent task execution** — 4 task types: Run Tests, Refactor Code, Dependency Scan, Create PR
- **Streaming log simulation** — per-task scripted log sequences delivered via `setTimeout` chains (600–1100ms cadence), matching real CI/CD output cadence
- **6-step execution timeline** — Initialize → Analyze → Install → Test → Report → Finalize, with live state transitions (pending / active / success / error)
- **Result summary** — test counts, issues detected vs fixed, duration, confidence rating, and PR link when applicable
- **Execution details drawer** — step-by-step breakdown with durations, log level summary counts, and full scrollable log output
- **Agent Runs history** — paginated run log across all repos with status, task type, duration, and trigger info
- **Integrations page** — connect/disconnect GitHub, GitLab, Slack, GitHub Actions, Datadog, PagerDuty
- **One-click retry** — clears in-flight timers and replays from scratch, no confirmation dialog
- **Toast notifications** — run start, completion (success/failure), retry, integration connect/disconnect

## Architecture

**Stack:** TanStack Start (SSR-capable React), TanStack Router, Tailwind v4, shadcn/ui, Sonner, Lucide React. No backend, no API calls — all data is mocked.

**Routing:** File-based. `routeTree.gen.ts` is auto-generated by the Vite plugin — do not edit directly. The `/repos/$repoId` route uses a `loader` to resolve the repo by ID and throws `notFound()` for unknown IDs.

**State machine (`useAgentRun`):** On `start(task)`, the hook schedules every log line and step transition via `setTimeout` chains keyed to a `taskStartedAt` timestamp. Stale closures are silently dropped when a retry fires. The 80/20 success/failure split is seeded once per `start()` call via `Math.random() < 0.2`. Cleanup runs on unmount and before each retry.

**Cross-component event:** The "Run Agent Task" button in `RepoHeader` dispatches `window.CustomEvent("agent:open-task-modal")`. `AgentPanel` listens for it in a `useEffect` to open `TaskModal`. This avoids threading modal state up through the page tree.

**Design tokens:** OKLCH color palette defined in `src/styles.css`. Key tokens: `--background #0B0E1B`, `--surface-1 #111827`, `--primary #7C3AED` (purple), status colors for `success`, `running`, `warning`, `error`. No light mode.
